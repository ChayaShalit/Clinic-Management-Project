# מרפאה דיגיטלית

מערכת לניהול מרפאה: מטופלים קובעים תורים וצופים בהפניות מהרופא, ורופאים מנהלים יומן, שעות עבודה והפניות.

## טכנולוגיות

- **צד לקוח:** JavaScript (Vanilla), Bootstrap (RTL), fetch
- **צד שרת:** Node.js, Express 5
- **מסד נתונים:** MongoDB (Mongoose)
- **אימות והרשאות:** JWT, bcrypt
- **ספריות נוספות:** Joi (ולידציה), multer (העלאת קבצים), pdfkit (דוחות PDF), nodemailer ו-node-cron (תזכורות במייל)

## סוגי משתמשים

| משתמש | מה הוא יכול לעשות |
|---|---|
| **מטופל/ת** | קביעת תור ביומן, צפייה בתורים הקרובים, צפייה בהפניות מהרופא, עדכון פרופיל ותמונה |
| **רופא/ה** | צפייה בתורים (להיום ולכל תאריך), הורדת דוח PDF של תורי היום, יצירת הפניה למטופל, עדכון שעות עבודה, הפסקות ויום חופש |

## מבנה הפרויקט

```
config/        הגדרות (משתני סביבה, חיבור למסד נתונים)
controllers/   הלוגיקה של כל פעולה
routes/        הגדרת הכתובות (endpoints)
models/        סכמות Mongoose
middlewares/   אימות, הרשאות, ולידציה, העלאת קבצים, טיפול בשגיאות
validators/    סכמות Joi
jobs/          משימות מתוזמנות (תזכורות)
client/
  pages/       דפי HTML
  js/          לוגיקה של כל דף
  services/    פניות לשרת (כתובת השרת מוגדרת ב-config.js)
  css/         עיצוב
index.js       נקודת הכניסה של השרת
```

## הרצה מקומית

1. התקנת חבילות:
   ```
   npm install
   ```
2. יצירת קובץ `.env` בתיקייה הראשית (הקובץ לא עולה לגיט):
   ```
   PORT=3000
   MONGODB_URL=<כתובת החיבור למסד הנתונים>
   JWT_SECRET_KEY=<מחרוזת סודית כלשהי>
   BCRYPT_ROUNDS=10
   EMAIL_USER=<כתובת מייל לשליחת תזכורות>
   EMAIL_PASS=<סיסמת אפליקציה של המייל>
   ```
3. הפעלת השרת:
   ```
   npm start
   ```
   (בזמן פיתוח: `npm run dev`, שמפעיל מחדש אוטומטית אחרי כל שינוי)
4. פתיחת הלקוח: פותחים את `client/pages/login.html` עם Live Server ב-VS Code.

כתובת השרת שהלקוח פונה אליה מוגדרת במקום אחד: `client/services/config.js`. לפני העלאה לענן משנים אותה שם.

## Endpoints עיקריים

כל הכתובות מתחילות ב-`/api`. "אימות" אומר שנדרש טוקן JWT בכותרת `Authorization: Bearer <token>`.

| פעולה | Method | כתובת | הרשאה |
|---|---|---|---|
| הרשמה | POST | `/auth/register` | פתוח |
| התחברות | POST | `/auth/login` | פתוח |
| שליפת פרופיל מטופל | GET | `/patient/:id` | מטופל |
| עדכון פרופיל ותמונה | PUT | `/patient/:id` | מטופל |
| רשימת רופאים ושעות עבודה | GET | `/doctors` | אימות |
| שעות העבודה שלי | GET / PUT | `/doctors/me/schedule` | רופא |
| שעות תפוסות ביום מסוים | GET | `/appointments/availability` | אימות |
| קביעת תור | POST | `/appointments` | מטופל |
| התורים שלי (מטופל) | GET | `/appointments/my` | מטופל |
| התורים שלי (רופא) | GET | `/appointments/doctor/my` | רופא |
| ביטול תור | DELETE | `/appointments/:id` | אימות |
| דוח PDF של תורי היום | GET | `/appointments/doctor/my/today/pdf` | רופא |
| יצירת הפניה (עם קובץ מצורף) | POST | `/referals` | רופא |
| הפניות של מטופל | GET | `/patients/:id/referals` | אימות |
| סימון הפניה כנקראה | PUT | `/referals/:referalId` | אימות |

## כללים עיקריים במערכת

- **Middleware מותאם:** `validateAppointmentTime` חוסם קביעת תור בשבת, ביום חופש של הרופא, מחוץ לשעות העבודה או בזמן הפסקה.
- תור אפשר לקבוע רק מהיום הבא והלאה, ולא לשעה שכבר תפוסה אצל אותו רופא.
- תזכורת במייל נשלחת למטופלים שביקשו אותה, בכל יום בשעה 09:00, על תור של מחר.
- סיסמאות מוצפנות עם bcrypt (hook מסוג `pre save` במודל User).
- העלאת קבצים: תמונת פרופיל וקובץ מצורף להפניה, עד 5MB.
- ולידציה בצד לקוח (HTML ו-JS) ובצד שרת (Joi ובדיקות בבקרים).

## חלוקת עבודה

| תחום | תוכן |
|---|---|
| אימות ופרופיל | הרשמה, התחברות, JWT, פרופיל מטופל ותמונה |
| רופאים ותורים | יומן, שעות עבודה, קביעה ועדכון של תורים, PDF |
| הפניות ותזכורות | הפניות עם קבצים, תזכורות במייל, העלאה לענן |
